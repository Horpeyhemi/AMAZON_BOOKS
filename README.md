# AMAZON BOOKS
Amazon Top 50 Bestselling Books 2009 – 2019
Data related to the top 50 best-selling books on Amazon for each year from 2009 to 2019.

### Key Insights ###
Name, Author, User Rating, Reviews, Price, Year, Genre

### Practice Questions ###
1. What is the average user rating of the books?
2. What is the correlation between price and user rating?
3. What is the proportion of books by genre?
4. Which author has the most bestsellers?
5. What is the distribution of reviews for the books?
